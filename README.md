Este arduino esta programado para hacer 2 motores girar de reversa al presionar un botón,
y ademas cuenta con un sensor ultrasonido que al momento de ponerle algo enfrente, 
el buzzer que tiene integrado comenzara a sonar dependiendo de la cercanía del objeto al sensor.
En el pdf de A2.4 Avances del proyecto se describe de mas el arduino, sus componentes, conexiones, codigo y resultados
En el codigo.ino esta el codigo del arduino listo para compilar y ejecutar en un arduino.
En pruebas de ejecucion.mp4 se muestra un video que desmuestra el funcionamiento de nuestro arduino
En conexiones.jpeg es una imagen que muestra nuestras conexiones.
